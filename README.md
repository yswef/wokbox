# متجر ووك بوكس — دليل التركيب والتوثيق

## المتطلبات
- PHP 7.4+ (يُفضّل 8.x) مع pdo_mysql و mbstring (و gd و zip للصور والنسخ الاحتياطي)
- MySQL / MariaDB
- Apache (ملفات .htaccess جاهزة). على Nginx يلزم منع الوصول إلى `config.php` و`lib/` و`storage/` يدويًا.

## التركيب (استضافة مجانية أو Hostinger)
1. من لوحة الاستضافة أنشئ قاعدة بيانات ومستخدمًا (MySQL Databases).
2. ارفع محتوى المجلد إلى `public_html` (أو مجلد فرعي).
3. عدّل `config.php` بقيم القاعدة (host/name/user/pass).
4. افتح `https://موقعك/install.php` وأدخل اسم المتجر وحساب الإدارة.
5. احذف `install.php` بعد التثبيت.
6. لوحة الإدارة: `/admin/` — فحص ذاتي: `/admin/selftest.php` (بعد تسجيل الدخول) ويكتب التقرير في `storage/selftest-report.txt`.
7. عدّل أرقام التواصل ورابط GitHub من الإعدادات.

## الانتقال إلى Hostinger لاحقًا (النسخ الاحتياطي)
1. من لوحة الإدارة ← النسخ الاحتياطي ← تنزيل (ZIP يشمل البيانات والصور).
2. على الاستضافة الجديدة: ارفع الملفات، عدّل config.php، شغّل install.php.
3. ادخل اللوحة ← النسخ الاحتياطي ← استعادة من الملف.
> الاستعادة تستبدل البيانات الحالية وتحفظ نسخة تلقائية قبلها في `storage/backups/`. حسابات الإدارة لا تُنقل.

## البنية
- `index.php` + `assets/store.*` — واجهة المتجر (السلة، الطلب، التتبع)
- `api/public.php` — واجهة العملاء (menu, quote, order, track, cancel)
- `api/admin.php` — واجهة الإدارة (جلسة + رمز CSRF)
- `admin/` — اللوحة، `invoice.php` للفاتورة الحرارية 80mm
- `lib/` — الإعدادات، الجداول، التسعير، النسخ الاحتياطي

## منطق مهم
- **التسعير يتم في الخادم فقط**: الأسعار، العروض، الكوبون، رسوم التوصيل تُحسب من القاعدة ولا تُقبل من المتصفح.
- أفضل عرض (الأقل سعرًا) يُطبَّق على المنتج. الكوبون على المجموع بعد العروض.
- رسوم التوصيل تُلغى إذا بلغ الطلب (بعد الخصم) حد التوصيل المجاني.
- إلغاء طلب بكوبون يُرجع استخدام الكوبون؛ إعادة تفعيله تُعيد الاحتساب.
- العميل يتابع الطلب برقم الطلب + الهاتف، ويستطيع طلب الإلغاء فقط وهو في حالة «جديد»؛ القرار للإدارة.
- حماية: PDO مُجهّز، throttle للطلبات وتسجيل الدخول، honeypot، جلسة HttpOnly، منع تنفيذ PHP في uploads.

## حدود معروفة
- لم يُختبر ضد MySQL حيّ في بيئة البناء؛ شغّل `selftest.php` وأرسل لي الناتج عند أي خلل.
- التنبيه الصوتي للطلبات الجديدة يعمل والتبويب مفتوح (فحص كل 15 ثانية).
